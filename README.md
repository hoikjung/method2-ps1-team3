# method2-ps1-team3

0. GitHub 를 사용하는 목적은 각자가 코드를 수정하면 이를 바로 업데이트하고,
   저장소에 보관하는 동시에, 팀원들과 공유하는 것에 있습니다. (동기화) 
2. 각자 레포지스토리에 R.md 파일을 업로드합니다. (PS1.영문이름.Rmd) 
3. R stuido 와 해당 레포지스토리를 연동합니다. (*연동 방법은 word 문서 참고) 
4. 내가 올린 (PS1.영문이름.Rmd) 을 열고, 작업 시작 전에는
   Environment 창에 Push 버튼을 누릅니다. (저장소의 최신을 내 R studio에 불러오는 것입니다)
5. 작업 수행 후 '저장' 합니다.
6. 저장을 누르면 오른쪽 Environment 창에 무언가 뜹니다.
7. 그곳에서 Staged를 체크하고 Commit을 누릅니다.
8. Commit 창이 새로 뜹니다. 그곳에서 Commit Message 메모를 입력합니다.
   그리고 Commit 을 누릅니다.
9. 이후 반드시 Push (화살표)를 누릅니다.
10. GitHub 웹페이지에 들어가면, 해당 내용이 업데이트된 것이 뜹니다.
11. 작업 시마다 이를 반복합니다.
    * 작업 시작 전 Pull, 작업 이후 저장->Commit->Push.
